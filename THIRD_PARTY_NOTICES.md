# Third-party notices

MIR2 is a clean-room implementation from published mathematical descriptions.
It does not link Essentia, librosa, FluCoMa, sc3-plugins, or a neural runtime,
and it contains no model weights or datasets.

The plug-in builds against SuperCollider's GPL-licensed server plug-in API.
Existing SuperCollider and sc3-plugins analyzers were inspected for interface,
behavior, and class-name auditing; their source was not copied into MIR2.
