# Listening and behavior checks

Before release, compare `Pitch`, `Tartini`, `FluidPitch`, `PitchYIN`,
`PitchMPM`, and `Pitch2` on the same legally available source material.
Listen specifically for dropout behavior, octave jumps, glissando lag, and
vibrato tracking rather than treating one implementation as ground truth.

For `Onsets2`, compare flux and SuperFlux-style modes on percussive material,
voice, and sustained vibrato. Record false triggers and missed attacks with
the same FFT size, hop, and minimum-gap settings.
